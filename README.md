# Hotstar Cloud Scaling

**Course:** IT457 — Cloud Computing  
**Group:** 19

## Project Overview

This project studies how cloud infrastructure handles sudden traffic spikes during high-concurrency live cricket events, using Hotstar as the case study.

The practical component will compare reactive autoscaling with pre-scaled capacity under the same simulated traffic profile.

## Objectives

- Study Hotstar's approach to handling large traffic spikes.
- Build a small API deployed behind a cloud load balancer.
- Configure automatic scaling of application instances.
- Generate controlled traffic using k6.
- Compare latency, error rate, scaling delay, instance count, and estimated cost.
